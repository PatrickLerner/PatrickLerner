---
title: Make It Write a Skill
date: 2026-09-02
theme: ai-in-practice
---

If your agent figured something out once, make it write it down.

Sometimes they are really dumb, and the solution it figured out last week is already forgotten. And it keeps burning tokens and time to solve things that are already solved.

Remember that each session starts fresh. Whatever the agent learned last time disappears unless someone told it to save it. Sometimes it remembers it automatically, but often not.

My preference is to ask it to create skills as soon as I can foresee that something becomes the norm. Skills are also portable and I can add them to my synced configuration setup, to move them to a new machine, or I can wire them into multiple tools (opencode, codex, claude), while memories are often specific to just one tool.

Plus you can share them with colleagues through a shared marketplace so that everybody can leverage them. Suddenly everybody can create agentic presentations on any topic, not just you.
