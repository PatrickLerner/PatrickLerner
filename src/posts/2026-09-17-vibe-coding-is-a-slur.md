Vibe Coding is a slur

If you are serious about the new way of work it should be agentic engineering.

The perception is that vibe coding is prompting without thinking and hoping the model figures it out. With agentic engineering, you steer a capable agent toward an outcome you already thought through. It has the same tools, same models, but it is a very different type of activity.

And yes agentic engineering can also be setting up the project, carefully adding rules, linters, test cases, review loops, revert and mitigation strategies, architecture and everything ahead of time so that once you ask an agent to do something it can feel like vibe coding. But the outcome is not random, but engineered.
